A single funny line, written by a tiny TypeScript program to `/output/entry.txt`.

> "I asked my horoscope for a refund, but apparently 'vague disappointment' isn't covered under warranty."

## Run

```sh
node main.ts
```

This writes the line (plus a trailing newline) to `/output/entry.txt` and prints the line with its character count. Set `ENTRY_OUTPUT` to write to a different path.
